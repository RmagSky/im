# im

IM Prototype Designs Via: Qdd

## 在线预览

- **交互原型（在线版）**：https://www.workbuddy.cn/space/d/NseQEzt3MmE80FbyjvgPjj

> 原型设计 · PROTOTYPE v1.0.0 — 单文件 HTML，无依赖，双击 `prototype/index.html` 即可本地打开。

## 内容

- 覆盖 4 个一级 Tab（对话 / 联系人 / 社区 / 我的）与 40+ 二级页面
- 完整交互：iOS 软键盘、消息长按/转发链路、好友分组管理、个人资料、深浅色主题
- 响应式：桌面端显示手机外框，移动端全屏

## 本地打开

直接用浏览器打开 `prototype/index.html`，或用深链直达任意页面评审，例如：

- 聊天页：`prototype/index.html#p=chat&id=c2`
- 群详情：`prototype/index.html#p=groupInfo&id=c1`
- 外观：`prototype/index.html#p=appearance`
